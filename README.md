# 表格均值，发给我自己

把一个 xlsx 里每一列的均值追加到数据最后一行，再通过企业微信把结果发给自己。

当前要怎么算、怎么发，写在 [`.cursor/skills/xlsx-wecom/SKILL.md`](.cursor/skills/xlsx-wecom/SKILL.md)。这个文件名必须是 `SKILL.md`，Cursor 才会把它当成技能。以后改需求，就改这个文件并推到 GitHub。

## 现在的规则

- 第一行是表头，不参与计算。
- 空单元格不计入均值。文字、日期、公式不参与。
- 均值四舍五入保留 4 位小数，写在最后一行。第一列不是数字时，这一格写「均值」。
- 不覆盖原文件，另存为「原文件名-均值.xlsx」。再跑一次会替换已有的均值行。
- 配好企业微信应用凭证后，把文字摘要和这个文件发给 `WECOM_USER_ID`。

示例：

| 姓名 | 语文 | 数学 |
| --- | --- | --- |
| 甲 | 90 | 70 |
| 乙 | 80 | 100 |
| 丙 |  | 90 |
| 均值 | 85.0000 | 86.6667 |

仓库里的 `examples/成绩.xlsx` 就是这张表。

## 本地运行

在项目根目录：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m xlsx_wecom examples/成绩.xlsx --no-send
```

`--no-send` 只生成本地文件。去掉它才会发企业微信。

## 企业微信

凭证放在环境变量或项目根目录的 `.env`，不要写进 Git。`.env.example` 里有空模板。

发给自己：

1. 企业微信管理后台创建一个自建应用。
2. 记下企业 ID、应用 Secret、AgentId。
3. 应用的可见范围加上你自己，通讯录里的账号填到 `WECOM_USER_ID`。
4. 四个变量都设置好之后，不带 `--no-send` 运行。

如果企业微信提示当前 IP 不能调用接口，把这台机器的公网 IP 加到应用的「企业可信 IP」。

只设置 `WECOM_WEBHOOK` 时，结果会发到群机器人。回复里会说明这是群消息，不是单发给自己。两类凭证都在时，只发给自己。

## 改需求

改小数位、表头、空单元格、「均值」这两个字、处理当前表还是全部表、是否覆盖原文件：只改 `SKILL.md` 里的 `skill-config`，然后重新运行。

改做法本身，例如改成中位数或改成发邮件：改 `SKILL.md` 上面的步骤，推到 GitHub，再让 agent 按新步骤改程序。只改步骤、不改程序时，程序仍按 `skill-config` 和现有代码运行。配置里出现程序不认识的项时，程序会停下来，不会悄悄按旧行为做完。
