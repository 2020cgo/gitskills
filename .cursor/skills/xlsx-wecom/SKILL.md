# 表格均值，并发给我自己

这份文件是当前需求。处理 xlsx 之前先读它。不要自行增加统计口径、图表或第二个发送渠道。

## 现在要做什么

用户给出一个 `.xlsx` 文件时：

1. 读下面的 `skill-config`。程序只认这个配置块里的参数。
2. 在项目根目录运行 `python -m xlsx_wecom <文件路径>`。不要手算均值。
3. 程序会把每一列的均值写到数据最后一行，并另存为新文件（配置为 `inplace` 时才覆盖原文件）。
4. 程序按配置把新文件和各列均值通过企业微信发出去。
5. 用中文回复用户，逐列写明均值。回复里的数字必须来自程序输出，不能改写。
6. 程序若说明没有配置企业微信或发送失败，就原样告诉用户。不要声称已经发出去。

只接受 `.xlsx`。用户给的是 `.xls` 或其他格式时，请对方另存为 `.xlsx`，不要换一套工具硬读。

## 计算规则

这些规则和 `skill-config` 是同一件事。两者冲突时，以 `skill-config` 为准，并告诉用户哪一条说明过时了。

- `header: true` 时，第一行是表头，不参与计算。表头用来称呼这一列。
- 参与均值的是单元格里的数字，以及纯数字文本（例如 `80`、`-1.5`）。
- 空单元格按 `blank_cells` 处理：`skip` 是跳过，`as_zero` 是按 0 计入。
- 文字、日期、布尔值、公式不参与。带单位或千分位的文本（例如 `12人`、`1,234`）不参与。
- 均值按四舍五入保留 `decimals` 位小数。
- 没有数字的列不写均值。第一列不是数字列时，均值行的第一格写 `label`（默认「均值」）。第一列是数字列时，第一格写该列均值，这一行加粗。
- 再跑一次时替换已有的均值行，不叠成两行。最后一行第一格如果就是 `label`，这一行视为已有均值行。
- `sheets: active` 只处理打开工作簿时的当前表。`all` 处理每张工作表。
- `output: copy` 时保存为「原文件名-均值.xlsx」，不改原文件。`inplace` 时覆盖原文件。

示例（`blank_cells: skip`、`decimals: 4`）：

| 姓名 | 语文 | 数学 |
| --- | --- | --- |
| 甲 | 90 | 70 |
| 乙 | 80 | 100 |
| 丙 |  | 90 |
| 均值 | 85.0000 | 86.6667 |

丙的语文是空单元格，不计入。数学均值是 (70+100+90)/3。

## 企业微信

凭证只放在环境变量或项目根目录的 `.env` 里，不要写进本文件，也不要写进仓库。

发给我自己（优先）：

- `WECOM_CORP_ID`
- `WECOM_SECRET`
- `WECOM_AGENT_ID`
- `WECOM_USER_ID`（填自己的账号，不能是 `@all`）

只配置了 `WECOM_WEBHOOK` 时，发到这个群机器人，并在回复里说明这是发到群，不是单发给自己。

两类凭证都有时，只发给 `WECOM_USER_ID`，不要再发到群里。

发送内容是两样：各列均值的文字，以及追加了均值行的 xlsx 文件。

## 改需求

改小数位、表头、空单元格、均值这两个字、处理哪张表、是否覆盖原文件：只改 `skill-config`，然后重新运行。

改步骤本身（例如改成中位数、改成发邮件、同时发到群里）：改上面的步骤并推到 GitHub，再让 agent 按新步骤改程序。只改步骤、不改程序时，程序仍按 `skill-config` 和现有代码运行。

`skill-config` 里出现程序不认识的项，或某项的值不在允许范围内时，程序会停止并指出这一项，避免按旧行为假装已经满足新需求。

```skill-config
label: 均值
header: true
decimals: 4
blank_cells: skip
sheets: active
output: copy
```
